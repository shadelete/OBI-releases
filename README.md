# OBI (Output Bazis Info) — розподіли

Тут лежать **збірки застосунку** для завантаження. Вихідний код — у приватному
репозиторії автора.

Завантажити останню версію: [Releases](https://github.com/shadelete/OBI-releases/releases/latest) ·
[усі версії](https://github.com/shadelete/OBI-releases/releases).

## Що всередині архіву

- `OBI.exe` — портабельний застосунок (без встановлення).
- `OBI.js` — скрипт для САПР «Базис», який збирає дані проєкту.
- `icon.bmp` — іконка.

## Як почати

1. Розпакуйте `OBI-<версія>.zip` у будь-яку теку.
2. У «Базисі» запустіть `OBI.js` — він випише JSON проєкту та запустить застосунок.
   Або просто відкрийте `OBI.exe` і вкажіть теку з JSON-файлами виробів.

Оновлення приходять самі: застосунок перевіряє цей репозиторій і пропонує нову
версію в Налаштуваннях → «Оновлення».

Питання і звірки про баги — авторам релізу.
